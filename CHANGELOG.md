# История изменений

## 0.1

Первый выпуск с утверждённым номером версии. Ранее подготовленные локальные сборки с обозначением 2.0 переименованы в 0.1 без удаления возможностей.

- Личный чат для текста, фото, видео и файлов до 512 МБ в одной домашней сети.
- Приложения для Windows 10/11 x64 и Android 8.0+.
- Выбор главного устройства при запуске и возможность изменить выбор.
- Главным устройством может быть Windows-ПК или Android-телефон.
- Поддержка Ethernet и Wi-Fi в одной локальной подсети.
- Поиск главного устройства и подключение по адресу и коду.
- Прямое подключение через физическую домашнюю сеть при работающем VPN, если системные правила разрешают обход; инструкция для Happ.
- История и оригиналы файлов хранятся на выбранном главном устройстве.

APK использует прежний ключ подписи и увеличенный внутренний номер сборки, поэтому устанавливается поверх предыдущей локальной сборки, несмотря на меньший отображаемый номер версии.

### Проверка и ограничения

Серверы и прямые шлюзы проверены автоматическими тестами. На Windows проверен Ethernet при включённом Happ. APK собран и подписан; на физическом Android и между двумя отдельными устройствами пока не проверен.

Автоматического переноса истории между главными устройствами нет. Изоляция клиентов роутером, брандмауэр и запрет соединений вне VPN могут препятствовать связи. Передача внутри доверенной локальной сети идёт без TLS и сквозного шифрования.
