# История изменений

## 0.1.2 — 7 ноября 2026

Исправлена ошибка подключения, когда главным устройством выбран Windows-ПК: телефон не мог установить TCP-соединение и показывал `failed to connect to /192.168.1.38 (port 4280) … after 4500ms`, хотя поиск в сети, интернет и пинг в локальной сети работали. Причина — входящие подключения к `Ryadom-Windows.exe` фильтровал брандмауэр: при выключенном брандмауэре Windows это оказался сторонний брандмауэр (ESET), а правила для приложения отсутствовали. Happ, кабель и роутер к ошибке отношения не имели.

**Windows**

- Новый модуль `windows/Firewall.cs`: определяет активные сторонние брандмауэры через `root\SecurityCenter2`, состояние профилей брандмауэра Windows, наличие входящих правил для приложения и профиль домашней сети (общедоступная/частная). Устаревшие записи Security Center без установленного продукта игнорируются.
- При первом запуске в режиме главного устройства приложение один раз на сборку показывает подсказку:
  - если активен сторонний брандмауэр — название продукта, порты TCP 4280 (чат) и UDP 42800 (поиск), где добавить правило, и предупреждение, что правила брандмауэра Windows при этом не действуют;
  - если включён брандмауэр Windows — предложение добавить входящие правила для `Ryadom-Windows.exe` только из локальной сети (один запрос UAC; правила `Ryadom chat TCP 4280` и `Ryadom discovery UDP 42800`).
- В меню значка Рядом добавлен пункт **«Проверить брандмауэр и сеть»** с текущим отчётом и подсказкой.
- Диагностический режим: `Ryadom-Windows.exe --firewall-check <файл-отчёта>`.
- Учитывается только профиль брандмауэра, применённый к домашней сети: включённый Domain-профиль на другом интерфейсе больше не даёт ложного вывода «брандмауэр Windows включён».
- Номер сборки Windows: 0.1.2.

**Android**

- Текст ошибки подключения теперь прямо говорит про входящие TCP 4280 и UDP 42800 на главном устройстве и сторонний брандмауэр (ESET, Kaspersky). `versionName` 0.1.2, `versionCode` 4 (устанавливается поверх 0.1).

**Документация**

- `docs/GUIDE.md`: новый раздел «Брандмауэр на главном Windows-ПК» — брандмауэр Windows, сторонние ESET/Kaspersky, «Доверенная сеть», смена профиля сети на «Частная», быстрая проверка `http://адрес:4280/api/health`.
- README: подсказка про брандмауэр в возможностях и обновлённые ссылки на выпуск 0.1.2.
- Версии интерфейса и сервера обновлены до 0.1.2.

## 0.1

Первый выпуск с утверждённым номером версии. Ранее подготовленные локальные сборки с обозначением 2.0 переименованы в 0.1 без удаления возможностей.

- Личный чат для текста, фото, видео и файлов до 512 МБ в одной домашней сети.
- Приложения для Windows 10/11 x64 и Android 8.0+.
- Выбор главного устройства при запуске и возможность изменить выбор.
- Главным устройством может быть Windows-ПК или Android-телефон.
- Поддержка Ethernet и Wi-Fi в одной локальной подсети.
- Поиск главного устройства и подключение по адресу и коду.
- Прямое подключение через физическую домашнюю сеть при работающем VPN, если системные правила разрешают обход; инструкция для Happ.
- История и оригиналы файлов хранятся на выбранном главном устройстве.

APK использует прежний ключ подписи и увеличенный внутренний номер сборки, поэтому устанавливается поверх предыдущей локальной сборки, несмотря на меньший отображаемый номер версии.

### Проверка и ограничения

Серверы и прямые шлюзы проверены автоматическими тестами. На Windows проверен Ethernet при включённом Happ. APK собран и подписан; на физическом Android и между двумя отдельными устройствами пока не проверен.

Автоматического переноса истории между главными устройствами нет. Изоляция клиентов роутером, брандмауэр и запрет соединений вне VPN могут препятствовать связи. Передача внутри доверенной локальной сети идёт без TLS и сквозного шифрования.
